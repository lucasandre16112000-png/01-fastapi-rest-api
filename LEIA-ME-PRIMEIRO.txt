⭐ CLIQUE DUAS VEZES NESTE ARQUIVO:

================================================================================
O QUE ACONTECERÁ
================================================================================

1. O script verificará se você está executando do ZIP
2. Se estiver, ele extrai automaticamente para o Desktop
3. Cria o ambiente virtual
4. Instala as dependências
5. Inicia a API
6. Abre o navegador automaticamente

================================================================================
SE COMECE_AQUI.bat NÃO FUNCIONAR
================================================================================

Siga estes passos SIMPLES:

1. Clique direito no arquivo ZIP
2. Selecione "Extrair tudo..."
3. Escolha um local permanente (Desktop, Documents, etc)
4. Clique em "Extrair"
5. Abra a pasta extraída
6. Clique DUAS VEZES em COMECE_AQUI.bat

Pronto! 🎉

================================================================================
APÓS INICIAR
================================================================================

Você verá:
   API: http://127.0.0.1:8000
   Docs: http://127.0.0.1:8000/docs

O navegador abrirá automaticamente com a documentação interativa (Swagger).

Para parar a API:
   Pressione CTRL+C

================================================================================
PROBLEMAS?
================================================================================

Se algo não funcionar:

1. Instale Python 3.9+ em: https://www.python.org/downloads/
   Marque "Add Python to PATH"

2. Reinicie o computador

3. Tente novamente

4. Se ainda não funcionar, clique em DIAGNOSTICO.bat
